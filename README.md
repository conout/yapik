# Япик

**Япик** — неофициальное Android-приложение для прослушивания подкастов и аудиокниг из Яндекс Музыки. Приложение собирает избранные подкасты и книги в одном месте, показывает новые выпуски и сохраняет прогресс прослушивания.

## Возможности

- авторизация через код устройства Яндекса;
- единая вкладка с избранными подкастами и аудиокнигами;
- обзор подкастов и книг по подборкам и категориям;
- автоматический поиск после ввода трёх символов;
- отображение новых выпусков;
- сохранение прогресса и продолжение с места остановки;
- фоновое воспроизведение и управление с экрана блокировки;
- переход к текущему выпуску из панели плеера;
- светлая и тёмная темы;
- обновление содержимого жестом вниз.

## Технологии

- Java 11;
- Android SDK, минимальная версия Android 8.0 (API 26);
- стандартные `HttpURLConnection`, `MediaPlayer`, `MediaSession` и SQLite;
- Android Keystore и AES-GCM для хранения OAuth-токенов;
- Gradle Kotlin DSL.

В приложении нет сторонних runtime-библиотек.

## Сборка

Откройте проект в Android Studio и дождитесь синхронизации Gradle либо выполните в корне проекта:

```bash
./gradlew assembleDebug
```

Готовый APK появится по адресу:

```text
app/build/outputs/apk/debug/app-debug.apk
```

Установка на подключённое устройство:

```bash
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

## Структура проекта

- `auth` — авторизация и обновление токенов;
- `data` — запросы к API Яндекс Музыки и получение ссылок на аудиопотоки;
- `model` — модели подкастов, книг и выпусков;
- `network` — сетевой клиент;
- `playback` — фоновый сервис воспроизведения;
- `storage` — локальная история, прогресс и настройки;
- `ui` — адаптеры списков и общий контроллер панели плеера.

## Важное замечание

Приложение использует внутренние методы API Яндекс Музыки. Они не являются публичным стабильным контрактом и могут измениться без предупреждения. Проект не связан с Яндексом и не является официальным клиентом Яндекс Музыки.

Перед публичным распространением необходимо настроить release-подпись, собрать release-версию и пересмотреть хранение OAuth-параметров в исходном коде.
